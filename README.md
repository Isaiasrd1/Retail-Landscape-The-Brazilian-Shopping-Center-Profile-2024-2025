# Retail-Landscape-The-Brazilian-Shopping-Center-Profile-2024-2025

# EN
This project proposes the creation of an AI agent in NotebookLM, conceived as a second brain specialized in the Shopping Center sector in Brazil. The agent uses as its basis the report "Profile of the Shopping Center Sector 2024/2025", from Abrasce - Brazilian Association of Shopping Centers, gathering data on sales, GLA (Gross Leasable Area), visitor flow, jobs, number of stores, and regional breakdowns.

The objective is to organize sectoral information, connecting data and generating strategic insights to support analysis, planning, and decision-making in the context of Shopping Centers, focusing on the period of 2023-2024 and using only the attributed sources.

Link to access: https://notebooklm.google.com/notebook/268f7347-94a9-4233-961b-2e222e2847a6


# PT
Este projeto propõe a criação de um agente de IA no NotebookLM, concebido como um segundo cérebro especializado no setor de Shopping Centers no Brasil. O agente utiliza como base o relatório “Perfil do Setor de Shopping Centers 2024/2025”, da Abrasce - Associação Brasileira de Shoppings Centers, reunindo dados sobre vendas, ABL, fluxo de visitantes, empregos, número de lojas e recortes regionais.

O objetivo é organizar e informações setoriais, conectando dados e gerando insights estratégicos para apoiar análises, planejamento e tomada de decisão no contexto de Shopping Centers, com foco no período de 2023-2024 e uso exclusivo das fontes atribuídas.
